> 发布仓库：https://github.com/liyu253178/qgis-airport-coverage
> 上一版本：v0.1.6（内置中国省市县行政区划）
> 本版本：v0.2.0（新增「制图输出」+ 修复 3 处崩溃）

## 一、本版新增：一键「制图输出」

新增 `export_dialog.py` + `figure.py` + `sci_map/` 模块，可在 QGIS 里一键导出期刊风格成果图（PDF / PNG / SVG / TIFF），无需再手动拼版。

### 1. 两种版面

| 版式 | 适用场景 |
|---|---|
| **右栏式** | 主图在左，统计信息 + 区位插图在右栏，适合 A4 竖版 |
| **单栏式** | 单图框，图例/比例尺内嵌在地图角落，适合横向单页 |

### 2. 图件要素

- **区位插图**：自动按地理形状纵横比适配尺寸（高长限高、宽扁限宽），不拉伸、不变形；右栏内水平居中
- **分区统计表**：自动统计每个机位的覆盖面积、并集面积、重叠面积（含实际投影坐标系下的实测值）
- **比例尺 / 指北针 / 图例 / 经纬网**：按页面尺寸自适应
- **图注建议**：自动给出可用于论文的图片说明文字

### 3. 坐标系

- 自动将 WGS84 数据投影到 **CGCS2000 3° 带**（按机位所在带），保证面积统计与图形不变形
- 例：广州（东经 113°）→ EPSG:4547；上海（121°）→ EPSG:4559

### 4. 导出选项

- 输出格式：PDF / PNG / SVG / TIFF（可多选）
- 分辨率：300 / 600 dpi
- 图例开关、区位插图开关、底图开关
- 可指定输出目录

## 二、本版修复的 3 处崩溃

v0.2.0 首次发布时存在 3 处会导致功能直接崩溃的缺陷，本版已全部修复：

| # | 位置 | 现象 | 根因与修复 |
|---|---|---|---|
| 1 | `export_dialog.py` | 一打开「制图输出」对话框就崩溃 | `_build_layers_box()` 先调用了 `_fill_layers()`，而后者要用的 `self.label_admin` 在其后才创建 → `AttributeError`。已把 `_fill_layers()` 移到 `label_admin` 创建之后 |
| 2 | `sci_map/core.py` `add_graticule` | **单栏式**版面直接崩溃 | QGIS 3.44 已将 `DegreeMinuteNoPadding` / `DegreeMinuteSecondNoPadding` 枚举改名，旧代码直接抛错。改为「无补零 → 基础名 → 有补零」逐名回退，跨版本可用 |
| 3 | `sci_map/core.py` `add_legend` | 图例文字超出页面被裁掉 | 图例原先直接显示临时图层原名（如「行政区划｜县（区）｜广东省｜广州市」，超长），且 `legend/title-label` 自定义属性在渲染阶段不可靠。改为在导出前直接把临时图层名替换为短标签（机位 / 覆盖范围 / 县（区）界），图例宽度随即收敛 |

## 三、本版 5 处排版优化

| # | 位置 | 优化 |
|---|---|---|
| 4 | `figure.py` `_build_inset` | 区位图**移除区县文字标注**——小图里「花都区/白云区/番禺区」等文字互相压叠、还被比例尺遮挡，现仅保留灰色同级色块 + 黑色主区域 + 轮廓 + 比例尺 |
| 5 | `sci_map/core.py` `add_inset` | 区位图**比例按地理形状自动适配**——可用区域 `max_w × max_h`，高长形状以高度为限、宽扁形状以宽度为限，始终保持纵横比不变形；右栏内水平居中、底部对齐 |
| 6 | `sci_map/core.py` `check_layout` | 消除「比例尺与地图重叠」**误报**——比例尺本就应放在图框内，新增 `_scalebar_linked()` 跳过这类误判。右栏式现为**零告警** |
| 7 | `sci_map/core.py` `add_legend` | 内嵌图例**按内容估算宽度**定位（新增 `_estimate_legend_width()`）——图例真实宽度要到渲染时才可知，摆放时读到的是默认值，会超框。右栏式 / 单栏式现均**零告警** |
| 8 | `sci_map/core.py` `add_legend` | 图例**短标签**显示（见上表第 3 项） |

### 区位图比例实测（广州，南北长的高长形状）

| 地理形状 | 纵横比 | 插图尺寸 |
|---|---|---|
| 高长（广州） | 1.7 : 1 | 31.8 × 54.0 mm（限高） |
| 方正 | 1 : 1 | 36.0 × 36.0 mm |
| 宽扁 | 0.6 : 1 | 36.0 × 21.6 mm（限宽） |

## 六、安装方式

1. 从 GitHub Release 下载 `airport_coverage-0.2.0.zip`
2. QGIS → 插件 → 管理并安装插件 → 从 ZIP 安装
3. 菜单「机场覆盖区规划 → 制图输出」即可使用

**兼容性**：QGIS 3.22 – 4.99（本版已在 QGIS 3.44.10 实测通过）。
