# 机场覆盖区规划（QGIS 插件）

用于**机场（大疆机场 / DJI Dock）覆盖区范围选择**。

大疆机场覆盖半径**综合考虑续航、航程、任务时间等因素，理论上限 5 km**；实际选址初筛建议
**4–5 km**（给往返航程、作业时间、安全电量、复杂环境留余量）。插件以 5 km 为默认半径生成
半透明覆盖圆，可复制、可随意拖动，并实时统计每个机位的覆盖范围、相互重叠与盲区。

跨平台：纯 Python + Qt，**同一份源码在 macOS / Windows / Linux 的 QGIS 上通用**，
要求 QGIS ≥ 3.22（本机实测 3.44.10）。

## 安装

1. 下载 Release 里的 `airport_coverage-0.2.0.zip`
2. QGIS → 插件 → 管理和安装插件 → 从 ZIP 安装
3. 勾选启用「机场覆盖区规划」

> 注意：ZIP 解压后顶层目录必须是 `airport_coverage/`（即 `airport_coverage/metadata.txt`），
> 多包一层目录会装不上。

## 功能

| 功能 | 说明 |
| --- | --- |
| 六类在线图源 | Esri 影像 / 谷歌卫星 / 星图地球 GEOVIS / 四维地球 / 吉林一号 / 天地图，均为 WGS84，面板一键加载；天地图影像与注记分两层，可单独叠加，key 在面板填写并存本机 |
| 覆盖圆 | 默认半径 5 km（理论参考上限，可改成 4–5 km 初筛）。点一下落一个圆，可复制、可拖动，半径恒为精确地面距离 |
| 行政区划 | 内置中国省（34）/ 市（375）/ 县（2890）三级边界，按当前视窗按需子集加载，自动套样式 |
| 拖动 | 按住圆拖动到任意位置，半径不失真（按新圆心重建）；拖动中橙色预览圈，Esc 取消 |
| 线测量 | 折线长度，随点击实时更新，右键/回车结束 |
| 面积测量 | 围成区域的面积与周长 |
| 统计 | 机位数、净覆盖面积、重叠面积与重叠率 |
| 导出 | 「导出机位方案」按钮导出 GeoPackage |
| **制图输出** | 一键导出期刊风格成果图（PDF / PNG / SVG / TIFF），含**区位插图、比例尺、指北针、图例、经纬网、分区统计表**；自动投影到 CGCS2000 3° 带，面积统计不变形 |

## 使用

1. 面板顶部选图源 → **加载底图**
2. 设半径（默认 5000 m，初筛建议 4000–5000）→ **添加机位** → 在地图上逐个点击落圆
3. **拖动机位** → 按住圆拖到合适位置（半径不变）
4. 需要边界时，在行政区划里选省市县 → **加载**
5. **线测量 / 面积测量** → 点击落点，右键或回车结束，Esc 清除，Backspace 撤销上一点
6. 选中有问题（比如被 QGIS 原生工具挪变形）的圆 → **重算所选** 按设定半径重建
7. 收工前点 **导出机位方案** 存成 `.gpkg`
8. 要出图时，点 **制图输出** → 选版面（右栏式 / 单栏式）与格式（PDF / PNG / SVG / TIFF）→ 导出。区位插图、比例尺、图例、分区统计表全部自动生成，无需手动拼版

## 借助 QGIS 平台：客户数据直接导入

插件运行在 QGIS 上，客户发来的数据可直接拖进工程与覆盖圆叠加：
TIF / TIFF、JPG / PNG 影像、SHP / GeoJSON / GPKG 矢量、KML / KMZ（谷歌地球画的机位、范围）、
CSV / 表格点位等，无需转格式。

## 两个必须知道的约定

### 1. 覆盖圆存在 memory 图层里，关闭工程即丢失

面板上的「导出机位方案」按钮是**必需的收尾动作**，不是可有可无的附加功能。

### 2. 圆的坐标系跟随工程，但半径是测地线生成的

- 图层 CRS = 工程 CRS（工程无空间参考则为 WGS84）
- 但圆的几何一律在「以圆心为中心的方位等距投影（aeqd）」里生成，再转回工程 CRS 存储

**为什么不能直接在工程 CRS 里 buffer(5000)**（实测数据）：

| 工程 CRS | 直接 buffer(5000 m) 的误差 |
| --- | --- |
| EPSG:4326 / 4490 地理 | buffer 单位是「度」，5000 度无意义 |
| **EPSG:3857 Web Mercator** | **北京 1175 m（23.5%），漠河 1965 m（39.3%）** |
| EPSG:32650 UTM 50N | 1.85 m |
| CGCS2000 高斯 3° 带 | 0.18 m |

> 加载 XYZ 底图时 QGIS 可能把工程 CRS 自动改成 3857。插件已处理：加载底图后会把工程 CRS 恢复原值。
> 若工程确实是 3857，5 km 圆在地图上会显示成南北拉长的椭圆 —— 这是墨卡托的正常现象，
> 建议改用 EPSG:4326 或当地高斯/UTM 带。

## 半径怎么定（重要）

- **5 km 是理论上限**：综合考虑续航、航程、任务时间等因素测算。
- **4–5 km 是推荐初筛半径**：给往返航程、作业时间、安全电量余量、复杂环境留余量。
- 覆盖圆只是**直线距离的初筛**；最终点位还要结合**地形遮挡、信号环境、航线高度、实际任务频次**复核。

## 文件结构

```
airport_coverage/
├── __init__.py            插件入口 classFactory
├── metadata.txt           插件元数据
├── plugin.py              主类：工具栏、菜单、工具调度
├── dock.py                机位面板（图源/行政区划/半径/列表/统计/导出）
├── geodesy.py             ★ 测地线圆生成、长度面积量算、格式化
├── basemaps.py            六类在线图源（含天地图 key 设置；加载后不改工程 CRS）
├── admin.py               省/市/县行政区划按需加载与样式、层级关系（出图区位插图用）
├── coverage.py            机位图层管理：增删、统计、导出 GeoPackage
├── export_dialog.py       「制图输出」对话框（右栏式 / 单栏式两种版面）
├── figure.py              成果图编排主入口
├── sci_map/               出图核心
│   ├── __init__.py
│   └── core.py            ★ 比例尺/指北针/图例/经纬网/区位插图/分区统计表/布局自检
├── tool_add_circle.py     点击落圆
├── tool_move_circle.py    拖动（QgsRubberBand 预览，按新圆心重建，保半径）

├── icons.py + icons/      各功能独立图标（含 figure.svg 制图输出）
├── data/                  省/市/县 GeoJSON、regions.json、boundary_lines.geojson
└── icon.svg
```

## 精度依据

所有算法结论均在本机 QGIS 3.44.10 上实测，详见仓库
`docs/QGIS插件-可行性验证报告.md`：

- 5 km 圆：aeqd 方案半径偏差 **0.000 m**；面积 78.5336 km²（πr² = 78.5398）
- 拖动：重建法偏差 0.000 m，单次 2.74 ms（60 fps 下拖动几十个圆不掉帧）
- 量算：北京→上海 1069.819 km（大圆真值约 1067 km）；不设椭球会返回 10.1，故插件显式设椭球
- 图源：各源 `isValid()` 均为 True，瓦片 HTTP 200 返回真实图像
